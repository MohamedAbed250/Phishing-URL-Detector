About the project

Machine learning phishing detection with explainable features.

This project was designed as a professional portfolio-ready web application that demonstrates backend engineering, ML integration, UI design, and production-oriented code structure in one cohesive system.

Purpose

The application helps users evaluate whether a URL is more likely to be legitimate or phishing by combining a trained RandomForest model with feature extraction and interpretable output.

Machine learning model

The detector uses a pre-trained scikit-learn RandomForestClassifier. Predictions include confidence scores from predict_proba and a risk-level interpretation for the UI.

Dataset

The project uses a phishing URL dataset converted from ARFF into train and test CSV files for structured model training. The backend keeps one canonical feature set so training and inference remain consistent.

Rows available: {{ model_info.dataset_rows or "N/A" }}

Feature extraction

Features include URL length, dot count, HTTPS usage, IP address usage, hyphen count, subdomain depth, redirects, DNS resolution, domain age, suspicious keywords, and selected HTML or script behaviors.
